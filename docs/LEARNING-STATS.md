# Прокачка Наруто — первый сквозной этап

Только ПК, клавиатура и мышь. Используется существующий профиль, XP и экономика.
Ctrl+1–5 или «+» на способности тратят очко; C открывает параметры. Все пять линий
сохранены. Пока runtime поддерживает изучение первого ранга Расенгана и клонов.
Следующие ранги и Гамакичи/Sage/KCM явно недоступны; очки сохраняются без выдуманной
кнопки покупки характеристик. Это не завершённый Naruto kit.

Из карты: cap30; STR16+1.4/ур., AGI15+1.1/ур. (не tooltip14), INT14+1/ур.;
HPbase300 +20HP за эффективный STR; броня +.2 за эффективный AGI. Сохраняются
сырые дробные значения. Текущая политика эффективного STR/AGI — floor с защитой
от погрешности floating-point; это обозначенная адаптация, не сертификация native
округления. STR бонусы сервер читает заново, в том числе при impact Расенгана.

Один начальный skillpoint и один за каждый новый уровень следуют документированному
native-default. Уровень сам по себе не выдаёт ранг. Первый Расенган требует4;
следующие source thresholds11/18 сохранены, но runtime рангов2/3 ещё не включён.
Первое обучение клонов с1 — временная MVP политика: native arlv остаётся unresolved.
Пять линий не заменяются дополнительными независимыми кнопками вариантов.

Обычная XP экономика и порог следующего уровня100+(уровень-1)*50 сохраняются как
настройки MVP и продлеваются до30. Native XP handicap175% не умножается повторно;
точные native пороги11–30 и взаимодействие handicap с AddHeroXP неизвестны.

Производные показатели:
- maxHP:300+20*STR+HP предметов; уровень1=620, уровень30=1420 без бонусов;
- броня:.2*AGI+броня предметов; используется прежняя MVP mitigation100/(100+armor);
- M1 multiplier:1+.02*(эффективный STR-16)+предметы — явно наш MVP баланс;
- maxMP1300+15*INT, MPregen.01+.05*INT — native-default inference, не точные
  Warcraft runtime totals; уровне1=1510/.71, уровне30=1945/2.16;
- скорость16+предметы, комбо5/5/7/10, восстановление10HP за уровень и прежняя
  стандартная регенерация HP остаются балансом прототипа, не заявленной parity.
Уровень/предметы не дают бесплатный полный refill; респаун восстанавливает героя.

Смерть сохраняет XP/ранги/очки/предметы. Reset нового матча очищает профиль.
Learning remote принимает только requestId, текущие character/LifeId, линию и epoch;
сервер проверяет фазу, участника, последовательность, уровень и очки. Дебет без yield.
Клиент не передаёт XP, цену, новый ранг или характеристики. Replays/rate-limit,
смена жизни и terminal не дают второй траты/новых рангов. Учиться можно у текущего
героя во время смерти до респауна; каст мёртвым по-прежнему отклоняется.
