# Дистанция между крипами и последовательность вышек

Крипы сталкиваются друг с другом. Круглый невидимый коллайдер диаметром 3,4 studs
не зависит от поворота конечностей и не расширяет зону попадания. Соседи держат
дистанцию около 4,2 studs, получают отдельные позиции по ширине маршрута и
резервируют свободные позиции вокруг цели. Ближние и дальние крипы используют
собственную дальность атаки. Обход соседей работает при движении; прыжки отключены.
Ожидание свободного места среди союзников не запускает удаление застрявшего крипа.
Мёртвый крип перестаёт блокировать путь сразу, затем удаляется по прежнему таймеру.

Поиск вышек своей линии охватывает 24 studs, чтобы крипы на дальнем краю строя
не пропускали вынесенную к обочине цель. Сами дальности ударов не изменены.
Сложная произвольная геометрия по-прежнему использует прежнее восстановление
движения; изменение предназначено для существующих маршрутов карты.

`StructureService.BlockingTier` ищет живые более ранние вышки той же команды
и линии. `DamageService.CanDamage` применяет эту защиту централизованно.
Порядок I → II → III независим для всех шести линий. База по-прежнему открывается
после всех девяти вышек стороны. Визуальная подсветка только сообщает состояние,
сервер не доверяет её видимости при расчёте урона.

Проверка `crowd-towers-qa.project.json` включает все шесть цепочек, запрещённый
урон, немедленное снятие/восстановление подсветки, бой 18 крипов и движение
союзной колонны через поворот. Измерения сохранены в `docs/evidence/minion-crowd-tower-chains.json`.
`tower-tiers-qa.project.json` дополнительно проверяет реальные выстрелы вышек,
продвижение крипа через три последовательные цели, награды и восстановление.
