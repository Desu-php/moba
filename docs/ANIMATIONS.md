# Подключение своих R15-анимаций

С этапа 5 пустой AnimationId включает процедурную анимацию R15: HeroPoses вычисляет позу, HeroMotionController плавно меняет Motor6D.Transform или AnimationConstraint.Transform на каждом клиенте. RigJoints сопоставляет суставы частям тела и обновляет их список при загрузке конечностей. Реализованы idle, бег с наклоном и руками назад, четыре разных M1 с замахом, печати рук при призыве, подготовка/удар Расенганом, толчок обеими ладонями и stun. Заполнять ID для первого запуска не нужно. Реальный визуальный результат ещё требует проверки в Studio: [план](COMBAT_UPDATE.md).

Опубликованный трек при доступности заменяет процедурную версию соответствующего действия. Общая архитектура и авторство: [HEROES.md](HEROES.md), [ASSETS.md](ASSETS.md). Урон всегда рассчитывается серверным временем, независимо от позы, трека и маркера Hit.

## Создание

1. В отдельной сцене Studio создайте R15-риг через Avatar → Character / Rig Builder. Используйте одинаковый тип рига для всех четырёх роликов.
2. Откройте Animation Editor на вкладке Avatar (также доступен через Window → Avatar), выберите риг и создайте Punch1, Punch2, Punch3, HeavyPunch.
3. Поставьте исходную позу, замах, контакт и возврат. Не включайте зацикливание. Рабочая длительность и момент контакта должны соответствовать таблице ниже.
4. В точке контакта добавьте маркер **Hit**. Он используется только для локальной подсветки руки; сервер не принимает от него решение об уроне.
5. Опубликуйте каждую анимацию через меню редактора **Publish to Roblox** от владельца игры или нужной группы. У игры должен быть доступ к ассету. Скопируйте четыре полученных ID.

Интерфейс и публикация описаны в [Animation Editor](https://create.roblox.com/docs/animation/editor), маркеры — в [Animation events](https://create.roblox.com/docs/animation/events).

| Слот | Контакт от начала | Длительность |
| --- | --- | --- |
| Punch1 | 0,10 с | 0,28 с |
| Punch2 | 0,10 с | 0,28 с |
| Punch3 | 0,12 с | 0,30 с |
| HeavyPunch | 0,18 с | 0,55 с |

Если ролики имеют другой ритм, меняйте HitDelayByComboStep и AttackDurationByComboStep в CombatConfig согласованно. Не удлиняйте ролик за пределы cooldown без изменения cooldown: сервер использует максимум cooldown и длительности.

## Подключение

Откройте src/shared/Config/AnimationIds.luau. Для героя OrangeNinja меняйте `ninjaSet`; `defaultSet` оставлен для Default и изолированной регрессии M1. Замените нужное пустое значение строкой вида rbxassetid:// и собственным числовым ID без пробелов. Сохраните файл, дождитесь Rojo и полностью перезапустите Play. Дополнительные ключи: Idle, Run, ShadowClones, SpiralSphere, WindPalm, Stun.

AnimationController использует Animator:LoadAnimation, кэширует треки, задаёт Priority = Action и Looped = false. Старые треки и подписки освобождаются при смене персонажа. Animator создаётся на сервере; стандартный Animator персонажа повторно используется. Локальное воспроизведение на персонаже игрока с серверным Animator реплицируется другим участникам по правилам Roblox. [Animator API](https://create.roblox.com/docs/reference/engine/classes/Animator).

Не создавайте второй Animator на клиенте и не запускайте вручную копии треков на каждом наблюдателе: это нарушит выбранную схему и может дать двойное воспроизведение.

## Проверка и ошибки

Запустите Server & Clients с двумя R15-игроками. С первого сделайте четыре отдельных нажатия, со второго наблюдайте четыре разных движения. Затем поменяйте роли. При подтверждении удара движение не должно начинаться заново; получение stun должно остановить ещё не завершённый замах. После respawn треки должны загружаться на новый Animator.

Пустой ID не является ошибкой. Ошибка загрузки непустого ID может означать недоступный ассет, неверного владельца, ограничение доступа или проблему сети. Проверьте ID и доступ в Creator Dashboard, а также Output клиента. Ошибки, возникающие асинхронно при скачивании ассета, дополнительно выводит сам Roblox. Пока трек не играет с ненулевой Length, остаётся процедурная версия.

R6 выдаёт отдельную диагностику: для этих роликов нужен R15. Если анимация не видна при валидном ID, проверьте RigType, наличие серверного Animator, ключ набора и длительность ролика.

Для собственных опубликованных роликов отдельно проверяются права доступа и репликация. Сцена Hero сравнивает Transform суставов обоих типов на клиенте-наблюдателе; старый тест счётчика логических запусков сохранён. Ни один из этих тестов не заменяет визуальную оценку всех движений, переходов и ракурсов на двух клиентах. В текущей итерации запуск Studio — **NOT RUN**.
