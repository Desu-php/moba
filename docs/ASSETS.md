# Происхождение ресурсов Stage 5

В эту итерацию не добавлялись скачанные модели, текстуры, анимационные ID, музыка, голоса, Toolbox-модели или извлечённые ресурсы игр. Герой — оригинальная упрощённая интерпретация визуального ориентира из задания, а не официально лицензированный персонаж Naruto. Переименование само по себе не является подтверждением прав на чужие материалы.

| Ресурс | Происхождение и авторство | Использование |
| --- | --- | --- |
| Волосы, повязка, эмблема, лицо, детали костюма, сандалии | Созданы в этом проекте кодом HeroAppearanceService в ходе Stage 5 | Parts/WedgeParts, цвета и WeldConstraint; нет внешних файлов или ID |
| Позы и плавное смешивание | Собственная хореография HeroPoses и HeroMotionController, созданная для проекта | Математические движения суставов; нет извлечённых ключевых кадров |
| Дым, вращающаяся голубая сфера, вспышка попадания и волна ветра | Собственный AbilityVFXController | Локальные примитивы, ограниченные временем и количеством |
| Базовый R15-скелет и стандартное управление | Встроенные компоненты платформы Roblox | Создаются Roblox при LoadCharacterAsync, используются внутри платформы; отдельная лицензия на экспорт/перепродажу здесь не заявляется |
| Шрифты интерфейса | Встроенные Enum.Font.Gotham/GothamMedium/GothamBold Roblox | Новые файлы шрифтов не поставляются |
| Опубликованные AnimationTrack | В поставке отсутствуют: все ID пусты | Не требуются для работы героя |
| Башни, кристаллы, постаменты, зарядка и энергетические импульсы | Собственные TowerFactory и TowerVFXController, созданы в итерации башен | Parts, встроенные материалы/цвета и программная анимация; внешних моделей и текстур нет |

У сторонних ресурсов нет неподтверждённых авторов или лицензий: сторонние загруженные ассеты в поставку не включены. Если позднее добавляется внешний ресурс, перед включением заполните запись: точный URL, автор/правообладатель, лицензия или письменное разрешение, разрешённые способы использования, ограничения, требуемая атрибуция и место хранения подтверждения. При отсутствии подтверждения оставьте процедурный вариант.

## Собственные опубликованные анимации

1. Создайте R15-ролики самостоятельно в Animation Editor и опубликуйте от владельца игры или группы. Проверьте доступ именно у целевого experience.
2. В `src/shared/Config/AnimationIds.luau`, в `ninjaSet`, укажите свои `rbxassetid://...`. Допустимые ключи: Idle, Run, Punch1, Punch2, Punch3, HeavyPunch, ShadowClones, SpiralSphere, WindPalm, Stun.
3. Синхронизируйте/пересоберите проект и заново запустите Play. Для M1 сохраните тайминги из CombatConfig; для способностей — из AbilityConfig. Маркеры не являются источником урона.
4. Проверьте два клиента: один выполняет действие, второй видит ровно одно движение. Проверьте отказ доступа, удалённый ID и отключение сети загрузки: вместо недоступного трека должна продолжаться процедурная поза.
5. Добавьте сюда для каждого опубликованного ID владельца, ссылку и подтверждение авторства/доступа. Не подставляйте случайные популярные ID.

Animator создаётся на сервере. Владеющий игроком клиент запускает его треки; наблюдатели используют штатную репликацию, без локального повторного Play. Для Idle/Run/способностей сервер предварительно проверяет загрузку через ContentProvider; для M1 сохранён прежний загрузчик с предсказанием. Процедурная поза отключается для конкретного действия только когда соответствующий трек реально играет и имеет ненулевую Length; отсутствие/ошибка загрузки сохраняет fallback. У клонов всегда процедурное воспроизведение.

Технические источники: [Animator](https://create.roblox.com/docs/reference/engine/classes/Animator), [Motor6D.Transform](https://create.roblox.com/docs/reference/engine/classes/Motor6D), [Animation Editor](https://create.roblox.com/docs/animation/editor). Документация API не является лицензией на произвольные ассеты каталога.
