# Ручной план проверки M1

Выполненные автоматические проверки записаны отдельно в [TESTING.md](../TESTING.md). Этот список не означает, что все ручные сценарии пройдены.

## Подготовка

Синхронизируйте существующую карту через Rojo. Остановите тест, выберите Server & Clients → 2 → Play / F7. Не используйте Run: нужны игроки и клиентские скрипты. R15 обязателен для подготовленных анимаций. Дождитесь окончания ForceField. Для визуальной оценки сначала подключите четыре собственных ID по [ANIMATIONS.md](ANIMATIONS.md).

В серверном Explorer смотрите Humanoid.Health и атрибуты Character: CombatState, ComboStep, CombatNextAttackAt, CombatStunUntil. Стандартная регенерация Roblox может увеличивать Health при долгих паузах. Автоматическая тестовая сцена отключает её у своих персонажей.

## Сценарии

| Действие | Ожидаемый результат |
| --- | --- |
| 4 клика с промежутком около 0,4 с, цель в 3–4 studs впереди | Health 100→95→90→83→73; четыре разных движения после подключения ID |
| Клик сразу после четвёртого | Нет пятого мгновенного удара; следующее комбо после 0,8 с начинается с 1 |
| Пауза более 1,2 с между началами атак | Новый удар наносит 5, шаг 1 |
| Один клик за 0,08 с до конца cooldown | Ровно один следующий удар на границе восстановления |
| Частые клики/удержание ЛКМ | Cooldown не обходится; удержание не создаёт бесконечную цепочку |
| Цель позади, в стороне, далеко; пустой замах | Урона нет, cooldown расходуется |
| Поворот во время замаха | Hitbox использует направление в момент контакта |
| Твёрдая стена между корнями | Нет урона сквозь стену |
| Две цели рядом впереди | Каждая получает урон один раз, независимо от числа частей тела |
| Попадание во время замаха цели | Её ещё не наступивший удар отменяется; во время stun новый M1 невозможен |
| Несколько stun подряд | Старый срок не снимает новое оглушение; после последнего срока движение возвращается |
| Финишер в открытом месте | Цель отлетает от атакующего, слегка поднимается; её комбо сброшено |
| Финишер возле стены и в углу | Нет пробивания и чрезмерного разгона; импульс возле стены сокращается |
| Попадания при ForceField | Нет урона, stun, толчка или подтверждённого hit-feedback |
| Смерть до момента контакта, затем respawn | Старый удар не наносит урон; новое комбо начинается с 1 |
| Выход одного клиента во время боя | Сервер продолжает работать, старое состояние удаляется |
| Атака второго клиента | Первый видит чужой удар, его собственное комбо не начинается |
| Переключение ролей атакующего и цели | Урон, stun и knockback одинаково работают в обе стороны |
| Открытый чат и клики по UI | Нет атаки от обработанного интерфейсом ввода |
| 30–60 секунд обмена ударами | Вспышки и искры исчезают; число эффектов ограничено, камера возвращается в исходное положение |
| CameraShakeEnabled = false и перезапуск | Попадания и VFX работают, тряски нет |
| DebugHitboxes = true и перезапуск | Короткая коробка появляется в момент проверки, затем исчезает |

## Задержка сети и восприятие

В настройках тестирования Studio задайте задержку сети, если она доступна в установленной версии, и повторите короткие серии при 100–200 мс и при более тяжёлой задержке. Проверьте мгновенный локальный замах, отсутствие повторного старта после подтверждения, остановку при отказе/stun и отсутствие урона от одного лишь предсказания. После очень долгой задержки допускается пропущенная визуальная атака: законченный удар не должен проигрываться заново.

На двух экранах проверьте фактическую репликацию AnimationTrack после подключения ID. Оцените, совпадает ли контакт кулака с серверным hitAt, не скрывают ли вспышки обзор и не мешает ли shake прицеливанию. Эти художественные и сетевые проверки не заменяются числовыми автотестами.

Дополнительно проверьте нестандартные размеры R15, прыжки, наклонные поверхности, движущиеся стены, плотную группу игроков и длительную сессию. Текущий автоматический прогон проверяет стандартный R15, статическую стену и локальную сеть Studio.

## Автоматическая сцена

Запустите scripts/check.ps1, затем откройте build/combat-tests.rbxlx отдельно от вашей карты. Выберите Server & Clients, 2 клиента, Play. Не управляйте персонажами во время прогона. Через примерно минуту после загрузки серверный Output должен содержать [M1Tests] ALL PASS; FAILED выводит имя проверки и стек.

В конце тест намеренно отключает второго тестового игрока для проверки очистки. Это нормальное завершение. Для повторного прогона нажмите End Session и Play. После изменения тестовых файлов сначала пересоберите сцену и заново откройте её с диска. Основной Rojo не подключайте к этой сцене.
