# Один матч на сервер

Жизненный цикл: `WaitingForPlayers → Preparing → InProgress → Finished`.
Разрушение трона завершает матч: победа выжившей стороне, поражение проигравшей.
Результат остаётся на экране. Автоматического нового раунда, таймера перерыва
или повторного распределения игроков нет. Новый матч требует нового сервера.

В production старт требует 5 игроков на каждой стороне. Studio использует
явное исключение 1×1 для небольших тестовых сцен. Уход во время подготовки
отменяет отсчёт; во время боя слот остаётся зарезервирован владельцу.
Переполнение наблюдает текущий матч. Поздний вход после победы не создаёт героя.

`RoundId` остаётся внутренним идентификатором сессии и не отображается в HUD.
Проверки epoch, жизни героя, принадлежности Character и одноразового эффекта
сохраняются. Устаревшие запросы не наносят урон, не покупают предметы и не
создают клонов. Клиент отклоняет игровые эффекты после `Finished`.

При завершении отключаются урон, NPC AI, башенные снаряды, способности и
возрождения. Созданные способности/клоны очищаются. Награды, золото, XP,
структуры и победитель больше не сбрасываются и не продолжают обновляться.

`tests/Rounds.spec.luau` проверяет terminal state и протокол в чистом Luau.
`tests/rounds/Runner.server.luau` разрушает башни и трон в Studio, отправляет
поздние события/запросы и ждёт 17 секунд — дольше прежнего цикла перезапуска.
Проверяет неизменный победный результат, отсутствие волн, дохода и возрождений.
Запуск: `build/round-tests.rbxlx`, Server & Clients, 2 клиента.

Верхний HUD содержит по пять собственных портретов героев, счёт и время.
Нижняя консоль объединяет портрет/уровень, способности, HP/MP, предметы и золото.
Текст о раундах, волнах и числе NPC в игровом HUD отсутствует. Полноценная
миникарта в этот этап не входит. Макет следует иерархии исторического
[Valve HUD redesign](https://www.dota2.com/700/hud/), без ассетов Valve.
